## Operating system

[riptide](https://github.com/businessbaum/riptide) is my own desktop operating system on Arch Linux. It looks and works like macOS, and I use it every day on my PC. Everything you see is my own code, running on the Hyprland window manager.

- Menu bar, dock, Launchpad, Spotlight, Mission Control, Control Centre and notifications
- System Settings with 19 pages, an App Store for the Arch repositories and Preview, my own PDF and image app
- Every app runs in a sandbox and has to ask before it can use the microphone, the camera, files or the network
- A safe login like on a Mac: nothing runs before the password is typed in
- Hourly snapshots, encrypted backups to an external disk and a way to roll back a bad update

Made with QML, Python, Lua and C++.
